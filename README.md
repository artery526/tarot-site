# 暖暖塔羅小屋

獨立於 Emily 手作工坊首頁的純靜態網站，使用 HTML、CSS 與原生 JavaScript，不依賴建置工具或後端。

## 本機預覽

在此資料夾執行：

```powershell
python -m http.server 8000
```

接著開啟 `http://localhost:8000`。也可以直接以瀏覽器開啟 `index.html`。

## 網站入口

此資料夾可作為獨立靜態網站部署根目錄。若要使用自己的獨立網址，需在發布平台建立獨立站點並連結此資料夾，再設定網域 DNS 與 HTTPS；本樣板不會導向 Emily 手作工坊。

## 網站功能

- 主視覺為 CSS 與 Emoji 組成的插畫佔位。
- 「免費抽一張牌」會從 78 張暖暖貓咪塔羅隨機抽牌，並隨機呈現正位或逆位，顯示對應牌義；可再次抽牌，同一瀏覽器畫面不會連續抽到同一張牌。
- 牌圖以 WebP 格式放在 `assets/tarot-cards/`，從 `D:\tarot\暖暖貓咪塔羅` 的 PNG 轉檔，原始圖檔保持不變。
- 逆位沿用同一張牌圖並在頁面旋轉 180 度，附有各牌對應的逆位解讀，不另存重複圖片。
- 抽牌在瀏覽器本機執行，不需註冊，不會把抽牌結果送到伺服器或儲存。
- 真人解讀詢問採兩步驟：第一步先完成簡單加法確認，再核對已結單訂單與總金額；第二步填稱呼、訂單 Email、問題內容。同一訂單限送出一次，問題寫入客戶單試算表的「塔羅小屋」分頁。後端部署設定請見 `backend/README.md`。
- 訂單驗證畫面提供「查詢訂單編號」視窗，可留在塔羅頁直接使用 Emily 手作工坊既有的訂單進度查詢服務；每次查詢後，本瀏覽器會冷卻 1 分鐘。
- 詢問表單不處理預約時段或付款。
- 關於文字、服務說明及隱私政策為首頁錨點預留位置。
