# 暖暖塔羅小屋

獨立於 Emily 手作工坊首頁的純靜態網站樣板，使用 HTML、CSS 與原生 JavaScript，不依賴建置工具或後端。

## 本機預覽

在此資料夾執行：

```powershell
python -m http.server 8000
```

接著開啟 `http://localhost:8000`。也可以直接以瀏覽器開啟 `index.html`。

## 網站入口

此資料夾可作為獨立靜態網站部署根目錄。若要使用自己的獨立網址，需在發布平台建立獨立站點並連結此資料夾，再設定網域 DNS 與 HTTPS；本樣板不會導向 Emily 手作工坊。

## 暫時內容

- 主視覺為 CSS 與 Emoji 組成的插畫佔位。
- 抽牌按鈕目前導向服務方案區，並提示體驗版尚未開放。
- 兩項真人解讀方案標示「即將開放」，不會建立預約或付款。
- 關於文字、服務說明及隱私政策為首頁錨點預留位置。
